

Aslan Emlak – Modern Gayrimenkul Portföy Yönetimi 🏠
İstanbul merkezli lüks gayrimenkul ihtiyaçlarına yönelik, Vanilla JavaScript ile geliştirilmiş, yüksek performanslı ve kullanıcı odaklı bir emlak listeleme platformudur.

🚀 Proje Hakkında
Aslan Emlak, karmaşık emlak verilerini modern bir arayüzle kullanıcıya sunan bir portfolyo çalışmasıdır. Proje, harici bir kütüphane (React, Vue vb.) kullanmadan, tamamen saf JavaScript ile dinamik içerik yönetimini ve modern UI/UX prensiplerini sergilemek amacıyla geliştirilmiştir.

✨ Öne Çıkan Özellikler
Dinamik İlan Yönetimi: Sayfa yenilenmeden ilanlar arasında filtreleme (Satılık/Kiralık) ve arama yapabilme.

Gelişmiş Modal Sistemi: Her ilan için detaylı bilgi, teknik özellikler ve iletişim seçeneklerini içeren modern açılır pencere (modal) yapısı.

Akıllı Arama: Semt, ilçe veya ilan başlığına göre anlık sonuç döndüren arama algoritması.

Modern Responsive Tasarım: CSS Grid ve Flexbox mimarisiyle her cihazda (Mobil, Tablet, Masaüstü) kusursuz görünüm.

Etkileşimli UI: Apple tasarım dilinden esinlenilmiş, yumuşak geçişler (transitions) ve gölge efektleri.

🛠 Teknik Mimari
HTML5: Semantik yapı ve SEO uyumlu içerik hiyerarşisi.

CSS3 (Custom Variables): Merkezi renk paleti yönetimi ve gelişmiş animasyonlar.

JavaScript (ES6+): DOM manipülasyonu, Array filtering ve dinamik içerik renderlama.

Google Fonts & Icons: 'Inter' font ailesi ile kurumsal ve okunabilir tipografi.

📂 Proje Yapısı
Plaintext

├── style           # Gelişmiş CSS (Root değişkenleri dahil)
